# v3.0 商业模式驱动的杜邦解读

**保存时间**：2026-07-24

## 核心升级

解读板块不再一刀切地列出三个指标，而是：

1. **先判定企业赚钱模式** — 6 种商业模式：
   - `品牌溢价型`（茅台、苹果）→ 重点看净利润率
   - `周转效率型`（京东、沃尔玛）→ 重点看资产周转率
   - `规模网络型`（腾讯、谷歌）→ 重点看净利润率改善
   - `杠杆经营型`（银行、保险）→ 重点看权益乘数
   - `周期重资产型`（船舶、钢铁）→ 重点看产能利用率
   - `早期投入/亏损`（优必选）→ 杜邦解释力有限

2. **针对性策略** — 每类给出适合该类企业的量化分析 + 选股建议

3. **重点指标高亮** — 解读卡片头部显示 🏗️ 品牌溢价型 → 重点看净利润率，颜色区分

## 判定逻辑

- **优先用 COMPANY_PROFILES.industry** 匹配行业规则
- **无 profile** 则从数据特征推断（npm>10%→品牌、at>1.5→周转、em>4→杠杆）
- **亏损** → lossmaking（ROE ≤ 0 且 net_profit ≤ 0）
