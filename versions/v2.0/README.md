# v2.0 相比 v1.0 新增

**保存时间**：2026-07-24

## 杜邦分解 Tab 三大新功能

### 1. 定性分析卡片（表格前）
- 行业标签 + 公司业务一句话定位
- 主营、护城河、周期属性四段描述
- 例如 JD：「中国自营 B2C 电商龙头，自建物流体系覆盖全国」
- 数据来源：`analyzer.py:COMPANY_PROFILES`（已覆盖 25+ 主流标的）

### 2. 解板块（表格后）
- **判定标签** 🌟 优质标的 / 📊 稳态中性 / 📉 回报偏低 / 🔴 警惕/亏损 / 🟡 周期/杠杆驱动
- **趋势研判**：最新 ROE 变化、解主要驱动因子（净利率/周转率/杠杆）
- **选股建议**：基于 ROE 趋势与质量对话式生成
- **警惕年份**：自动检测异常年度并列出原因
  - 净亏损但 ROE 为正（杠杆掩盖）
  - ROE 同比大幅下滑 > 5pct
  - 周转率同比骤降 > 50%
  - 杠杆同比骤升 > 50%

### 3. 表格 emoji 标注
- 🏆 最优年份
- ⚠️ 最差年份
- 🔔 警惕年份（多个可能同时出现）
- 表头上方有图例说明

## 测试用例

- **JD**：profile 电商零售、tag 📊 稳态中性、advice 提示 ROE 下滑需考察
- **NVO**：profile 医药 GLP-1、tag 视数据而定
- **00700.HK**：tag 🌟 优质标的
- **600150.SH**：造船 ship，profile 船舶制造 + 强周期
