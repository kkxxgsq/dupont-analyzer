# v1.0 版本说明

**保存时间**：2026-07-24  
**状态**：当前运行版本，已测试通过

## 已实现功能

- ✅ 美股 / 港股 / A 股三大市场支持（基于 AKShare 公开数据源）
- ✅ 中文名搜索 + 自动补全（`COMMON_STOCKS` 表，50+ 主流标的）
- ✅ 自动市场识别（不带后缀时用正则判断）
- ✅ 三因子杜邦分解（ROE = NPM × AT × EM）
- ✅ 多年度趋势分析 + 历年 DuPont 表
- ✅ 最优/最差年份对比卡 + 差距归因（净利率/周转率/杠杆贡献）
- ✅ Chart.js 4 趋势图（单只与多只对比）
- ✅ 多股票对比表格 + 对比图
- ✅ 同业推荐（PEER_GROUPS）+ 卡片点击跳转
- ✅ Tag 点击切换激活股票 / "回到对比"按钮
- ✅ 24h 文件级缓存（pickle），避免重复拉慢数据
- ✅ 前端 90s AbortController 超时保护
- ✅ Docker 部署文件（Dockerfile + docker-compose.yml + .dockerignore）
- ✅ 快捷入口（京东 / 腾讯 / 茅台 / 诺和诺德 / 阿里 / 特斯拉）

## 已知限制

- A 股首次加载需 1-3 分钟（EastMoney API 限制，缓存后秒级）
- 同业映射仅覆盖主要行业头部公司，未做动态发现
- 暂不支持财务年度自定义范围（固定 2018+）

## 回滚方式

`cp versions/v1.0/* .` 即可恢复。
