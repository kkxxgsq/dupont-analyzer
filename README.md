# 杜邦分析 — Dupont Analyzer

[![v7.3](https://img.shields.io/badge/version-v7.3-4a6cf7)](https://github.com/kkxxgsq/dupont-analyzer/releases/tag/v7.3)

基于公开财报的 **ROE 杜邦分解系统**，支持 **A 股 / 港股 / 美股** 三市场。  
输入股票代码，自动抓取 5 年财务数据，分解 ROE 驱动因素（净利率 × 周转率 × 杠杆），判断增长质量，辅助基本面分析。

---

## 功能一览

### 杜邦分析（核心）

| 指标 | 公式 | 含义 |
|------|------|------|
| 净利率 | 净利润 ÷ 营收 | 盈利水平 |
| 资产周转率 | 营收 ÷ 平均总资产 | 运营效率 |
| 权益乘数 | 平均总资产 ÷ 平均股东权益 | 杠杆水平 |
| **ROE** | 净利率 × 周转率 × 杠杆 | 股东回报率 |

- 5 年财务数据自动抓取，资产/权益使用年初年末平均值
- 最优年份 vs 最差年份自动对比 + ROE 驱动因素拆解
- 商业模式智能分类（品牌溢价型 / 周转效率型 / 网络平台型 / 杠杆经营型 / 周期重资产型 / 亏损期）
- 自动生成中文解读：趋势判断、核心指标跟踪、品质标签、选股建议、警惕年份检测
- 同类公司参考推荐

### 五大估值计算器

| 指标 | 衍生分析 |
|------|----------|
| **PE-TTM** | PEG = PE ÷ 利润CAGR(3Y)，低估/合理/高估判断 |
| **PB** | PB/ROE 比值，破净提示 |
| **PS** | PSG = PS ÷ 营收CAGR(3Y)，PS÷净利率≈隐含PE |
| **PCF** | 现金流充裕度，PCF/CAGR 类PEG，PCF vs PE |
| **EV/EBITDA** | 行业参考区间，EV/EBITDA÷CAGR 类PEG，与 PE 对比 |

- 商业模式自动匹配推荐度（⭐⭐⭐/⭐⭐/⭐）
- 一键获取实时行情数据（腾讯 API）
- CAGR(3Y/5Y) + 年均 ROE 自动计算

### K 线 + GMMA 技术分析（A 股）

- 基于 lightweight-charts 的日 K 线图 + 成交量
- 顾比均线：紫色短组（6/12/18/24/30 EMA）+ 橙色长组（36/42/48/54/60 EMA）
- 信号栏自动判断：站稳/突破/跌破/收窄/发散
- 时间范围切换：3M / 6M / 12M / 3Y / 5Y

### 股票性质定位 + 对冲建议

- **九宫格分类**：市值（大盘/中盘/小盘）× 风格（价值/均衡/成长）
- **周期/防御标签**：基于行业与周期描述自动标注
- **对冲建议**：按行业匹配对冲标的（国债期货、商品期货、股指期货、行业ETF等）

### 多股对比

- 同时展示 4 只股票的杜邦分解
- 对比表格：公共年份 × 各股核心指标
- 对比趋势图（ROE / 净利率 / 周转率 / 杠杆）

### 数据导出

| 格式 | 内容 |
|------|------|
| **Markdown** | 全量分析报告（含 inline 趋势图 base64） |
| **PNG（杜邦分解）** | 公司概览 + 表格 + 解读 |
| **PNG（最优/最差年份）** | 对比卡片 + 差距分析 |
| **PNG（趋势图）** | 4 图 2×2 网格 |
| **PNG（估值卡片）** | 五大估值计算器结果 |
| **PNG（多股对比）** | 对比表 + 4 张对比图 |

## 快速开始

```bash
pip install -r requirements.txt
python main.py
# 访问 http://localhost:8765
```

或 Docker 部署：

```bash
docker compose up -d
# 访问 http://localhost:8765
```

> 完整部署指南见 [DEPLOY.md](./DEPLOY.md)

---

## 使用方法

1. 输入股票代码（如 `AAPL`、`00700`、`600519`），回车添加
2. 查看杜邦分解表格 + 自动解读
3. 点击「对比」添加竞品，对比分析
4. 点击「估值参考」展开五大估值计算器
5. A 股卡片点击「📈 GMMA」查看 K 线 + 顾比均线
6. 使用顶部导出按钮导出报告

## 数据源

| 数据 | 来源 |
|------|------|
| 美股财报 | akshare → 东方财富 |
| 港股财报 | akshare → 东方财富 |
| A 股财报 | akshare → 东方财富 |
| A 股 K 线 | akshare → 前复权日线 |
| 实时行情 | 腾讯行情 API `qt.gtimg.cn` |
| 图表库 | Chart.js 4 + Lightweight Charts 4 |
| 图片导出 | html2canvas 1.4 |

数据缓存 24h（K 线 1h），支持 `/api/cache-clear` 手动清除。
