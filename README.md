# 杜邦分析 — Dupont Analyzer

[![v7.1](https://img.shields.io/badge/version-v7.1-4a6cf7)](https://github.com/kkxxgsq/dupont-analyzer/releases/tag/v7.1)

基于公开财报数据的杜邦分解系统，支持 **A股 / 港股 / 美股** 三市场。  
输入股票代码，自动抓取财务数据，分解 ROE 驱动因素，辅助判断增长质量。

---

## 功能一览

### 杜邦分解（核心）

| 层级 | 公式 | 含义 |
|------|------|------|
| ROE | 净利润 / 股东权益 | 股东回报率 |
| 净利润率 (npm) | 净利润 / 营业总收入 | 盈利水平 |
| 资产周转率 (at) | 营业总收入 / 总资产 | 运营效率 |
| 权益乘数 (em) | 总资产 / 股东权益 | 杠杆水平 |

- 5 年财务数据自动抓取（可配置年份）
- 同行竞品横向对比（同时展示 4 家公司）
- 环比变动趋势图（ROE / npm / at / em）

### 估值计算器

- **四维估值**：PE / PB / PS / PCF 并行计算
- **PEG 分析**：结合增长率判断估值合理性
- **商业模式推荐排序**：根据行业属性自动匹配最优估值模型（消费→PE、周期→PB、烧钱→PS、重资产→PCF）
- **CAGR 自动计算**：TTM / 3 年 / 5 年 复合增长率

### K 线 + GMMA 技术分析（A 股）

| 功能 | 说明 |
|------|------|
| K 线图 | 基于 lightweight-charts，支持 3M/6M/12M/3Y/5Y 时间范围 |
| 顾比均线 (GMMA) | 短组 6/12/18/24/30 + 长组 36/42/48/54/60 |
| 信号分析 | 自动判断突破/跌破/收窄/发散，信号栏显示在图表上方 |
| EMA 期号标签 | 每条均线右侧标注期号 + 数值（如 `6  123.45`） |
| 配色优化 | 紫色系（短组）+ 橙黄色系（长组），与 K 线红绿区分 |

### 数据导出

- **Markdown 导出**：杜邦分解 + 估值结果 + 环比趋势
- **图片导出**：对比图表截图中日
- **HTML 导出**：包含完整图文的单页文件

## 快速开始

### 本地运行

```bash
pip install -r requirements.txt
python main.py
# 访问 http://localhost:8765
```

### Docker 部署

```bash
docker compose up -d
# 访问 http://localhost:8765
```

> 完整部署指南见 [DEPLOY.md](./DEPLOY.md)

---

## 使用方法

1. 在搜索框输入股票代码（如 `AAPL`、`00700`、`600519`）
2. 点击搜索，系统自动抓取数据并显示杜邦分解
3. 点击「对比」添加竞品股票
4. 点击 K 线图标（A 股）查看 GMMA 技术分析
5. 使用「导出」按钮导出分析报告

---

## 数据源

- **A 股 / 港股 / 美股**：东方财富 + akshare
- **实时行情**：腾讯 API
- **数据缓存**：24 小时 TTL，支持 `/api/cache-clear` 清除
